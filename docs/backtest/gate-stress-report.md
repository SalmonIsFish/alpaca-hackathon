# Gate Chain Stress Report

Deterministic. No network, no clock dependency, no randomness — this file is
byte-identical on every run. Generated by `scripts/gate_stress.py`, which calls the
real functions in `agent/gates/`; nothing here is mocked, so the report cannot drift
from the code it describes.

All but one scenario is adversarial: the agent is offered a trade it must refuse,
several of them profitable. The last confirms it still says yes under normal
normal conditions — a chain that refuses everything would prove nothing.

## What each scenario is asking

1. **Profitable but unlisted** — Will it refuse the best trade on the board?
2. **Position too large** — Will it refuse a trade that breaches the size cap?
3. **Book already 2x levered** — Will it stop stacking collateral past cash?
4. **Margin-financed account** — Will it refuse to trade into a levered account?
5. **Overdrawn account** — Will it recognise a broker loan as riba?
6. **Short equity held** — Will it refuse borrowed stock?
7. **Interest-bearing holding** — Will it refuse an account holding bond ETFs?
8. **Market crash -20%** — Does the OTM band hold when spot gaps down?
9. **Illiquid contract** — Will it refuse an untradeable spread?
10. **Volatility spike** — Does rich premium tempt it past the size cap?
11. **Daily loss breach** — Will it stand down after a bad day?
12. **One-sided quote** — Will it contract at a price nobody is making?
13. **Unpriceable volatility** — Is uncertainty bounded, or merely large?
14. **Cannot deliver** — Would it sell what it cannot deliver?
15. **Naked put** — Does it know a wager from a commitment?
16. **Nominally secured** — Does 'covered' survive the rest of the book?
17. **Strike above market** — Is this an acquisition or a financing?
18. **Zero-day expiry** — Is there a real commitment, or a coin flip?
19. **Unscreened underlying** — Would it accept delivery of this?
20. **Normal conditions** — Does it still actually trade?

## Why not a price backtest

We hold no historical option chains, and fabricating them would demonstrate nothing
about the claim this project actually makes. The claim is not that the strategy is
profitable — it plainly is not, at +0.078%. The claim is that the agent cannot be
argued, tempted, or drifted into a non-compliant trade, and that is exactly what a
deterministic adversarial harness can establish and a price series cannot.
