# Amanah Trader — Alpaca AI Trading Agents Hackathon

A Shariah-compliant autonomous options-trading agent built on Alpaca's paper trading environment
for the **Alpaca AI Trading Agents Hackathon** (lablab.ai, Aug 28 – Sep 4, 2026, Options Alpha
Agents track).

Before an order can be placed, it must clear a deterministic compliance gate chain: is the
underlying company Shariah-permissible, is the option structure itself permissible, is the
account free of interest-bearing exposure, and does it fit within risk limits. Nothing reaches
the broker without clearing every gate, and every decision is recorded with its evidence.

Broker: **Alpaca**, paper trading only. No real capital.
